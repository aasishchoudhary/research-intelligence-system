# Engineering Instructions

1. Evidence before assertion.
2. Never fabricate sources, citations, measurements or test results.
3. Keep deterministic validation outside the model.
4. Distinguish implemented, tested, experimental and planned behavior.
5. Prefer typed schemas and small composable modules.
6. Add regression tests when behavior changes.

Before completion: run tests, inspect provenance behavior, check unsupported claims, update documentation, and state limitations.
